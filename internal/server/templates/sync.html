Set up an app

rclone (Linux, macOS, Windows)

Add goftp as a remote, then sync a folder both ways. The first run needs --resync; run the second line again whenever you like, e.g. from cron. With vendor=infinitescale, rclone sends files in 10 MiB pieces, so files of any size get through proxies that limit requests, and keeps their times.

rclone config create goftp webdav url={{.URL}} vendor=infinitescale user={{.Username}} pass=APP-PASSWORD --obscure
rclone bisync ~/goftp goftp: --exclude ".*" --exclude ".*/**" --resync
rclone bisync ~/goftp goftp: --exclude ".*" --exclude ".*/**"

FolderSync (Android)

Under Accounts, add a WebDAV account with the server address, your username and an app password. Then add a folder pair of a folder there and one on the phone, with the sync type Two-way.

GoodSync (Windows, macOS)

Choose WebDAV for one side of a job and enter the server address, your username and an app password; choose the folder to sync for the other side. Then analyze and sync.

Mountain Duck and Cyberduck (macOS, Windows)

Make a bookmark or connection of the type WebDAV (HTTPS), paste the server address into Server, and enter your username and an app password. Mountain Duck shows goftp as a disk; its Smart Synchronization keeps the files you open on your computer.

Finder and other file managers

In Finder, choose Go → Connect to Server and enter the server address. Most Linux file managers open {{.FileManagerURL}}.

  • Apps see and change what you may on the site, no more{{if .Home}}, and what they put in your home counts toward its quota{{end}}.
    • {{if .Trash}}
  • Files that a sync deletes go to the trash, where you can restore them for a while.
    • {{end}}
  • Names starting with a dot, such as .git, are not synced: goftp hides them. macOS's .DS_Store and ._ files are taken and dropped.
  • Changing your password revokes all your app passwords.
